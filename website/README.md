# xean website

A single-page static site inspired by the spare layout of [knowyourshit](https://github.com/amoreX/knowyourshit), with an ivory, sage, and deep teal palette. The implementation is plain HTML, CSS, and JavaScript; there is no build step or dependency installation.

## Preview

From the repository root:

```sh
./start-site.sh
```

Open `http://127.0.0.1:4173`. Python 3 is the only requirement; no account, Node.js, or package installation is needed. Keep the terminal running and press Ctrl+C to stop it. Use `./start-site.sh 4174` to choose another port. The launcher works from any working directory.

## Contents

- `dist/index.html`: three-line hero, install chooser, simulated macOS desktop, interactive product preview, and a footer wordmark with Nihal’s X link.
- `dist/styles.css`: responsive layout, local fonts, responsive controls, 240 ms disclosures and staged removal animations, and reduced-motion support.
- `dist/app.js`: agent installation prompt, clipboard feedback/fallback, install chooser, and sound control.
- `dist/demo.js`: synthetic app state, live metrics, category inventories, cleanup queue, and automatic walkthrough.
- `dist/sounds.js`: Web Audio playback of the native app’s Cuelume cues: interactions at 70% volume and the one-time wordmark intro at 28%.
- `dist/assets/fonts`: self-hosted Manrope and Instrument Serif with their SIL Open Font License notices.
- `dist/assets/github.svg`: GitHub mark from [Octicons](https://github.com/primer/octicons), with its MIT license in `octicons-LICENSE.txt`.
- `dist/assets/sounds`: seven cues from the app’s `Sources/BlitzClean/Resources/Cuelume` directory; their MIT license is included as `LICENSE.txt`.

On page load, the hero, description, actions, desktop preview, wordmark, and creator credit fade upward in a short stagger. Each group takes 520 ms; the full entrance finishes in 800 ms. The demo waits for its own entrance to finish before starting the storage alerts. Keyboard focus reveals controls immediately, and Reduce Motion shows the page without this animation. The CSS entrance works without JavaScript and leaves no hidden state behind.

Get xean expands into two choices. **Let your agent do it** copies a setup prompt and shows “Prompt copied”; if clipboard access fails, a selectable text field provides the prompt. **Do it yourself** opens the repository’s installation instructions.

The browser preview starts with a simulated macOS desktop, Finder window, dock, and menu bar. Three low-storage popups appear in sequence before the cursor moves; these are decorative example alerts, not browser or native notifications. The sample disk starts at 4.7 GB free and increases as cleanup progresses. A cursor clicks xean’s eraser icon, opens the panel, and the camera zooms in over 800 ms before the walkthrough continues. The desktop frame and camera share a fixed stage on wide screens so the surrounding page stays still. On narrow screens the preview expands downward during the zoom to keep its controls readable without reserving a large blank area. Clicking the menu bar icon opens the panel manually; closing returns to the desktop. The zoomed preview uses a compact 420 × 496 panel on larger screens, with its width and height adapting on phones and in landscape. Mobile layouts include 44-pixel checkbox and primary-action targets, 16-pixel numeric inputs, safe-area padding, and natural scroll chaining back to the page. Opening the panel manually scrolls it into view. The preview uses a continuous curved popover outline with a rounded notch aligned under the menu bar icon. One clipped glass surface fills both the notch and body, without a seam or overlapping diamond, and follows panel resizing and the compact quit state. It has a clear, lightly frosted backdrop with a 24% neutral tint and retains the native cleaner’s categories, settings, row-only scroll blur and a transparent edge fade (no extra backdrop strip; older browsers retain the fade), compact quit confirmation, and cleanup/result screens. It uses example paths and sizes and never reads, scans, or deletes visitor files. The silent walkthrough reveals its cursor for the first menu bar click, then keeps it visible between actions, through scrolling, cleanup, zoom-out, and subsequent loops. It stays within the desktop preview and moves continuously from its last position. Manual interaction, an offscreen preview, a hidden tab, or Reduce Motion hides the simulated cursor. It enables Auto-clean through its inline confirmation, then turns on Notify when low to show the warning badge. It opens Claude Code and old worktrees, with 650 ms scrolling and short reading pauses. All other categories remain available for manual exploration. It selects worktrees, shows the protected item, then turns Show menu bar stats off once before clicking Clean. The individual metric switches remain available for manual use. Switch thumbs briefly widen on press, hover shading stays subtle, and metric widths ease over 200 ms while the eraser remains fixed. Pointer coordinates are derived from each real control, so clicks stay aligned after zooming or scrolling. A small click ring and button press make each action clear. After cleanup, the cursor clicks Done before returning to the desktop. The checking screen keeps the selected queue visible; each removed entry gets the same red center-out sweep, short slide/fade, and height collapse as the native app, one row at a time at 264 ms per item (48 ms lead-in, 80 ms sweep, 16 ms hold, 56 ms departure, 64 ms collapse), 2.5× faster than the previous demo. The checking pause is 200 ms and the final settle is 72 ms. Cleanup numbers ease to their new values over 160 ms; ordinary metric changes still take 400 ms. The success screen stays visible for 3.2 seconds before the next cycle. Interacting pauses the walkthrough for manual exploration; reloading starts it again. There are no playback or sound controls below the preview. Reduced Motion disables automatic playback and camera/row movement; the menu bar icon still opens the preview immediately. The app walkthrough stays silent; sound cues accompany user actions and the one-time footer intro described below.

No analytics, remote fonts, or browser storage are used. The preview is implemented in HTML/CSS; the installed app uses native SwiftUI and AppKit components.

The footer wordmark extends the existing [OriginKit Weight Hover](https://www.originkit.dev/components/weight-hover) inspiration into a continuous pointer interaction. Each letter lightens, lifts, and leans according to the pointer’s distance, with smooth easing between positions and a slightly deeper response while pressed. After the page entrance, a single 1.6-second sweep previews the same interaction from left to right. Its first appearance plays the bundled 850 ms “ready” chime at 28% volume when browser autoplay permits. Blocked or slow audio is skipped rather than queued for a later click. Taking over the wordmark, leaving view, or hiding the page fades out the cue; it never repeats during that page load. It waits until at least half the wordmark is visible, so phones do not spend the preview offscreen. Pointer interaction takes over immediately. If the wordmark leaves view or the tab is hidden before the sweep finishes, it waits to show the cue when visible again; a completed sweep never loops. Moving away restores the resting wordmark. Touch presses use the same effect without blocking page scrolling. Fixed letter slots prevent layout shifts and the creator credit stays still. Reduce Motion disables the effect; hidden pages cancel pending frames. `footer.js` uses requestAnimationFrame only during the preview or while values are settling and a locally bundled Manrope variable font from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/manrope), with its SIL Open Font License alongside it. No OriginKit source code or React runtime is bundled.

The website source lives in the [xean fork](https://github.com/amoreX/xean) alongside the native app. Deploy `website/dist/` to any static host with no build command. Optional local hosting metadata is ignored by Git; the site has no dependency on ChatGPT Sites.
